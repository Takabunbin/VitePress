# 02 · 固件调整到 1.2.8

## 进入系统设置

打开：

```text
http://192.168.31.1
```

进入：

```text
常用设置 → 系统设置 → 手动升级
```

选择 AX6000 的 `1.2.8` 固件并开始升级。

::: danger 升级过程中禁止操作
开始写入后不要断电、拔网线、Reset 或关闭设备。
:::

## 重启后验证

重新登录后台，确认显示：

```text
系统版本：1.2.8
```

如果版本不是 `1.2.8`：

<div class="stop-line">停止，不继续获取 STOK 或执行漏洞 URL。</div>

## 完成检查

- [ ] 后台可正常登录
- [ ] 系统版本明确显示 `1.2.8`
- [ ] 路由器工作正常

<div class="step-ok"><strong>完成条件：</strong>版本必须为 1.2.8。</div>
