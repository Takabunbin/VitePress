# 09 · LAN / WAN 基础设置

## 1. 先保持电脑 DHCP 自动获取

Windows 网卡 IPv4：

```text
自动获得 IP 地址
自动获得 DNS 服务器地址
```

## 2. 如果上级路由器也是 192.168.1.1

OpenWrt 默认 LAN 也常用 `192.168.1.1`，会冲突。

可以改为：

```text
192.168.100.1
```

LuCI：

```text
网络 → 接口 → LAN → IPv4 地址
```

保存应用后重新访问：

```text
http://192.168.100.1
```

## 3. WAN 接线

```text
上级路由器 / 光猫
        │
        ▼
   AX6000 WAN
        │
        ▼
   AX6000 LAN ──> 电脑
```

WAN 默认 DHCP 的情况下，通常会自动获取上级网络地址。

## 4. IPv6

不要仅因为某篇教程建议就立即永久禁用 IPv6。

是否关闭取决于你后续使用的代理、分流和上游网络方案。

## 5. 完成检查

- [ ] 电脑能获取 AX6000 LAN 地址
- [ ] LuCI 可以打开
- [ ] WAN 可以获取上级地址
- [ ] LAN 与上级网段不冲突
- [ ] root 密码已设置
