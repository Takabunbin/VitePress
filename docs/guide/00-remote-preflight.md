# 00 · 远程环境验收

::: danger 这不是普通本地刷机
你的目标是：**人在外地，通过远控操作妹妹那边的 Mac，再由 Mac 的 USB-C 有线网口直连 Redmi AX6000。**

远程刷机最大的致命风险不是命令本身，而是 **AX6000 一重启，你同时失去远程控制 Mac 的网络**。
:::

## 最终采用的拓扑

```text
互联网
  │
家里现有 Wi-Fi / 主路由
  │  无线
  ▼
Mac（远控主机）
  │
  │ USB-C → RJ45 扩展坞/网卡
  │
  ▼
Redmi AX6000 LAN 口
```

**必须分成两条独立链路：**

- Mac Wi-Fi：只负责互联网 + RustDesk/ToDesk 等远控
- Mac USB Ethernet：只负责访问 AX6000

AX6000 重启、掉 DHCP、从 `192.168.31.1` 变成 `192.168.1.1` 时，Mac 的 Wi-Fi 远控不能受影响。

## 百兆有线网口是否足够

足够。刷机镜像只有几十 MB，真正耗时的是 NAND 写入，不是百兆/千兆链路。

如果价格差距很小，可以买千兆 USB-C → RJ45；但对刷机安全没有本质区别。

## 远控存活测试：必须先做

### A. Mac 只靠 Wi-Fi 上网

先让 Mac 连家里正常 Wi-Fi，确认：

```text
Safari/浏览器能上网
远控软件在线
你可以稳定控制 Mac
```

### B. 插上 USB 有线网卡，但先不接 AX6000

确认远控仍然在线。

### C. 接 AX6000 LAN

确认远控仍然在线。

### D. 模拟 AX6000 消失

让妹妹：

1. 拔掉 AX6000 电源
2. 等 30 秒
3. 你继续操作 Mac

必须满足：

```text
AX6000 已断电
但你的远程桌面仍正常
```

如果远控断线：**停止，禁止刷机。**

### E. 再模拟 AX6000 网线断开

妹妹拔掉 Mac ↔ AX6000 网线，等待 30 秒。

你仍然必须能正常控制 Mac。

## Mac 有线网口的关键配置

原厂阶段建议给 USB Ethernet 静态地址：

```text
IP：192.168.31.10
子网掩码：255.255.255.0
路由器 / Gateway：留空
DNS：留空
```

重点是：**USB Ethernet 不设置默认网关。**

这样 macOS 会把：

```text
192.168.31.0/24 → USB Ethernet
互联网 → Wi-Fi
```

分开处理，避免有线口抢走默认路由导致远控掉线。

进入 OpenWrt initramfs 后，再只把 USB Ethernet 改成：

```text
IP：192.168.1.10
子网掩码：255.255.255.0
路由器 / Gateway：留空
DNS：留空
```

Wi-Fi 从头到尾不动。

## Mac 必须满足

- [ ] 接电源
- [ ] 禁止自动睡眠
- [ ] 刷机期间不要合盖
- [ ] 远控软件允许无人值守
- [ ] 远控软件开机自动启动
- [ ] 最好准备第二套远控软件作备用
- [ ] 妹妹在现场，能按 Reset、拔插电源、确认灯色和网线位置

## 现场人员只需要会四件事

妹妹不需要懂 OpenWrt，只需要在你明确指令下：

1. 看灯颜色/闪烁状态
2. 拔电源
3. 插电源
4. 按住/松开 Reset

不要让现场人员自行判断“是不是该重启”。

## 绝对禁止

::: danger 红线
- 远控 Mac 的互联网经过正在刷的 AX6000
- Flash 写入过程中断电
- 不知道当前系统分区就猜 `mtd8/mtd9`
- 使用 ubootmod 镜像刷 stock-layout 流程
- 远程情况下先刷第三方 U-Boot
- 原厂备份只留在 `/tmp`
- 依赖在线脚本到刷机中途再下载
:::

## 验收门槛

只有以下全部通过才进入下一页：

- [ ] Mac Wi-Fi 独立联网
- [ ] USB-C Ethernet 已识别
- [ ] AX6000 断电时远控不掉
- [ ] AX6000 网线拔掉时远控不掉
- [ ] 有线口不承担默认网关
- [ ] Mac 不会睡眠
- [ ] 妹妹现场可配合物理操作
- [ ] 刷机固件已提前下载
- [ ] 计划使用 **OpenWrt 官方 stock layout**

<div class="step-ok"><strong>全部通过才继续。</strong> 任何一项不满足，都不开始刷机。</div>
